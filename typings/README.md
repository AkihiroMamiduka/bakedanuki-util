# Vendored type stubs

`maya/` contains the type stubs distributed as `maya-stubs`.

- Upstream: <https://github.com/Muream/maya-stubs>
- Version: 0.4.2
- License: MIT
- License copy: `LICENSES/maya-stubs-LICENSE.txt`

The installed distribution uses the directory name `maya-stubs`.
It is stored as `typings/maya` here because Pyright custom stub packages use
the import package name under the configured `stubPath`.

These files are used only for static analysis. Maya runtime modules continue
to come from the `mayapy` interpreter selected by each developer.

## Local modifications

None. The files under `maya/` are copied unchanged from `maya-stubs 0.4.2`.
